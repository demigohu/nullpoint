# NullPoint docs

How NullPoint works, how it's built, what it trusts, and a Verify page that checks the security claims against the chain on every load.

```sh
npm run dev   # from the repo root: web on :3000, docs on :3001
```

`NEXT_PUBLIC_APP_URL` and `NEXT_PUBLIC_REPO_URL` set the header links (see the root `.env.example`).
